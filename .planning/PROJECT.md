# RoboFleet Project Blueprint

## Vision
AI-led operations command centre and digital twin for robot-assisted dark stores.
Deterministic core, realistic Indian quick-commerce data pack, physical safety guardrails, 2D/3D browser command center, AI operational brain with governance and heuristic fallback, resilience and chaos testing, and a reproducible evidence-backed pitch kit.

## Phases
- [ ] Phase 1: Dynamic Core and Realism Pack
- [ ] Phase 2: Live Data and 2D Command Centre
- [ ] Phase 3: Fleet Engine and Baseline Operations
- [ ] Phase 4: 3D Experience
- [ ] Phase 5: AI Operations Brain
- [ ] Phase 6: Exceptions, Verification and Resilience
- [ ] Phase 7: Evidence, Pitch and Flagship Hardening

## Governance Protocols
- Karpathy Guidelines (SR-1 - SR-4)
- Agent Skills (SDLC /spec, /plan, /build, /test, /review, /ship)
- Ponytail (Minimal viable diff, YAGNI)
- GSD (Plan-execute-verify, atomic commits, milestone tagging)
- Anti-slop Frontend & Impeccable (Operate mode, dense data, zero placeholders, high craft)
